# 将 Harness engineering 融入 InferBench

- 状态：completed
- 创建日期：2026-08-21
- 关联 PR：#5

## 目标

把智能体优先工程从文章原则转化为仓库内可导航、可执行、可机械验证的开发环境，同时保留管理员对 PR 合并和发布版本的最终判断。

## 非目标

- 不引入自动合并。
- 不让智能体自动选择或创建发布 Tag。
- 不在本地构建 Docker 镜像。
- 不在本期引入外部可观察性平台或分布式执行环境。

## 实施结果

- [x] 使用短 `AGENTS.md` 提供仓库地图和关键不变量。
- [x] 建立设计、产品契约、执行计划和质量索引。
- [x] 增加仓库结构、版本、链接和发布规则检查器。
- [x] 提供本地与 CI 共用的验证入口。
- [x] 增加 PR 模板和定期质量反馈任务。
- [x] 保留管理员合并与 Tag 二次确认门。

## 决策日志

| 日期 | 决策 | 原因 |
|---|---|---|
| 2026-08-21 | `AGENTS.md` 只做地图 | 减少上下文占用和规则腐烂，详细事实进入结构化文档。 |
