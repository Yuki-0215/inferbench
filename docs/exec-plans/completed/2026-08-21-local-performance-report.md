# 本地图文性能报告 v1

- 状态：completed
- 创建日期：2026-08-21
- 负责人：Codex
- 关联版本：0.1.6

## 目标

一个并发矩阵的全部 run 结束后，InferBench 自动生成一份完全本地、可追溯的图文性能报告草稿。报告需要展示核心指标、并发扩展、延迟、稳定性、错误和 Token 速度，使用确定性规则给出饱和点与推荐并发，并支持 JSON、HTML/打印 PDF 和长图导出。

## 非目标

- 不调用外部 LLM 或报告 API。
- 不采集服务端 GPU 遥测。
- 不引入新的数据库服务或对象存储。
- 不在本地构建 Docker 镜像。
- 不在本期生成服务端二进制 PDF。

## 约束与不变量

- 报告事实必须来自持久化的 run 与 sample，不能由模型猜测。
- 报告生成失败不得改变 benchmark 的完成状态。
- API Key、完整 Prompt 和响应正文不得进入报告。
- 报告必须记录分析版本、run IDs 和生成时间，允许未来重新生成。
- 没有用户 SLO 时，只能给出“默认平衡规则”推荐，不能声称生产最优。
- 三轮配置不兼容或样本不足时，必须降低报告可信度并说明原因。
- 现有数据库必须原地升级，不迁移或删除历史数据。

## 风险、回滚与后续

- 自动生成应使用幂等 upsert，避免重复报告。
- 大量样本不应直接塞入报告 snapshot，只保存聚合结果与引用。
- 如果前端导出长图受浏览器安全策略影响，应降级为下载 PNG。
- 后续可增加环境模板、可选 AI 文字润色和 GPU telemetry adapter。
