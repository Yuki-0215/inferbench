# 执行计划

计划是仓库中的一等工件，用于让长任务在上下文切换后仍可继续，并让决策与验证证据可追溯。

## 何时创建

满足任一条件时，从 [template.md](template.md) 创建计划：

- 跨越三个以上组件或文件类别。
- 涉及数据迁移、发布、权限、安全或不可逆操作。
- 需要多个验证阶段或预计无法在一次短工作中完成。
- 需求存在需要管理员判断的架构取舍。

小改动可以在 PR 描述中记录轻量计划，无需单独文件。

## 生命周期

1. 在 `active/` 创建 `YYYY-MM-DD-topic.md`。
2. 工作中持续更新进度、决策和新发现，不依赖聊天记录。
3. 完成后补齐验收证据并移动到 `completed/`。
4. 未完成但暂缓的工作写明阻塞条件；技术债务同步到 [../QUALITY.md](../QUALITY.md)。

计划描述目标与约束，不复制大量实现代码。
